# 三路单节锂电池充电器

本工程用于三路独立单节锂电池充电，主控为 STM32G031，充电管理器件为 BQ24040。工程包含固件、原理图和 PCB 设计文件。

## 目录

- `code/`：STM32 固件、驱动、界面和测试工具。
- `pcb/`：Altium 原理图、PCB、封装库和发布文件。
- `doc/`：芯片资料和设计依据。

## 固件

使用 Keil MDK 或 GCC 工具链编译 `code/` 工程。烧录前确认目标芯片、供电电压和调试接口连接正确。串口调试输出使用工程配置的串口参数。

`code/README-bringup.md` 记录上电检查、引脚连接和外设验证步骤；`code/connectivity-check.md` 记录原理图与 PCB 网络复核结果。

## 硬件

PCB 文件位于 `pcb/Triple 1S Battery Charger/`。充电状态、按键、OLED 和三路电池接口均应以最新原理图为准。修改 PCB 前请保留原始工程文件和库文件。

## 注意事项

充电电流和电池状态必须通过实板测量确认，软件指示不能替代充电安全保护。编译输出、历史备份和临时日志已由 `.gitignore` 排除。
