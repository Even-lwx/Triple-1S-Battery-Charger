# 三路 1S 充电器初始化与上板验收

实现日期：2026-10-28。STM32G031C8T6，HSI/PLL 64 MHz，STM32 HAL G0 V1.6.3。
按 embedded-project-planner 工作流实施；保留原工程，未改写 pcb/doc，未创建新提交。

## 上电行为

1. HAL、时钟初始化；USART1 PA9/TX、PA10/RX，115200、8N1。
2. 初始化按键、LED、OLED 控制和 ISET2 GPIO，逐项输出 `[INIT] ... OK/FAIL code=...`。
3. SPI1 模式0、MSB先发、1MHz；ADC1 时钟16MHz，160.5周期采样，执行校准。
4. SSD1306 128×64 初始化并显示启动页。型号与7P针序已由用户确认；128×64分辨率按常见0.96寸模块配置，需实物核验。
5. GPIO启动先置三路ISET2悬空100mA，随后从Flash恢复上次保存的三路设定；无有效记录时保持100mA，逐路记录初始化结果。
6. 首次采样后每秒刷新输入电压、三路电池电压、电流、设定电流；串口另外输出 VDDA、NTC 原始码与电压范围状态。

显示中的 ISET 是设定档位，B1/B2/B3 的 MA 是实际 ADC 测量值。
PG/CHG 只接板载 LED，没有接 MCU，程序不能宣称“充满”或准确识别电池存在。
LOW/OPEN 只表示低电压或空载疑似状态。输入4.4–5.5V、电池2.5–4.25V仅用于调试分档，不能替代充电保护。

## 三档电流与按键

| 档位 | ISET2电平/模式 | 实际含义 |
| --- | --- | --- |
| 100mA | 无上下拉输入/悬空 | BQ24040低电流档 |
| 500mA | 推挽高 | BQ24040中电流档 |
| 1000mA标称 | 推挽低 | 电阻设定档；图中560Ω按540/R计算约964mA |

四键菜单已替代直接切档：PB4=上，PB5=下，PB6=确认，PB7=返回。
总览用上下选择通道，确认进入详情；详情确认进入菜单，总览返回也可打开菜单。
菜单包括电流设置、三路恢复100mA、说明页。电流设置上下移动光标，确认才应用，返回取消。
软件30ms消抖，长按不重复；同时按键忽略，返回键优先取消；开机按住不会直接改变档位。
1.5秒电池启动动画可由任意键跳过，跳过的按键不会改变电流；动画期间继续采样。
从500mA恢复悬空时直接切输入，不先拉低，避免过渡到电阻设定的最大电流档。
`Board_SetCurrent()` 返回明确结果，`Board_GetCurrent()` / `Board_CurrentMA()` 查询软件设定。

ISET2没有“关闭充电”功能。原图 TS pin9 各接10k到地，PG/CHG只接LED。
为防上层误用，`Board_SetChargeEnabled()` 两种请求均明确返回 `BOARD_UNSUPPORTED` 并记录原因，且不改变GPIO。
默认100mA仍然允许充电，MCU复位期间也无法靠固件停止充电。
充电器自身的恒流恒压、热调节与输入限流可能使实际充电电流低于所选档位。

## 错误与诊断

初始化失败输出阶段和状态码。GPIO成功表示寄存器配置读回一致；OLED成功只表示SPI传输完成，没有屏幕读回应答。
ADC校准失败不进入采样，采集超时、VREF异常或电流ADC饱和时整帧无效，清除valid并在OLED显示错误，不继续显示旧数值。
OLED刷新失败记录错误并停止后续刷新；输入/电流监测和串口继续。三个MCU LED现专用于对应三路充电估计状态，PC13不再作为全局数据有效指示。
USART自身失败或早期时钟失败会进入停止路径，调试器读取 `board_fault.stage/code/uart_errors`。
该记录仅当前启动有效，不承诺复位后保留；没有串口时不虚称已发出串口消息。
HAL发送有超时，日志接口仅供主循环调用，不可用于IRQ/多任务并发。

## 三路LED与预设电流显示

LED4/PC13=通道1，LED5/PB8=通道2，LED6/PB9=通道3，均为低电平点亮。
`charge_led.c` 独立管理状态和非阻塞1Hz闪烁（500ms亮/500ms灭）。用户实测空载约1mA，暂按下列门限，需上板校准：

- ≤3mA持续3秒：熄灭，清除此前充电记录。
- ≥8mA持续2秒：闪烁，记录本次曾检测到充电电流。
- 曾进入闪烁状态，且电压≥4.15V、电流>3mA并≤max(10mA,预设电流/10)，持续30秒：常亮，仅表示“疑似充满”。
- 3–8mA的非满电候选区间维持原指示以减少抖动；数据失效、输入不在4.4–5.5V或电池电压不在2.5–4.25V时立即熄灭并清除历史。

空载优先：充满后的电流若也降到≤3mA，同样会熄灭，不能与拔掉电池可靠区分。
空载脉冲、并联负载、ADC零偏或低输入均可能影响推断。常亮不是BQ24040终止充电信号确认；准确判断仍需额外CHG/在位反馈。
开机直接插入已满电池且没有检测到明确充电电流，不直接宣称满电。状态变化串口输出EMPTY/UNKNOWN、CHARGING-EST或FULL-EST。

总览表头 `V I/SET MA` 表示电压及“实测电流/预设电流”，例如 `3.79 483/1000`。
单路详情另设 `SET 1000MA`，即使ADC异常或存在输入警告也显示预设值。1000mA仍是名义电阻档。
新增LED仿真覆盖低有效引脚映射、闪烁相位、空载优先、持续时间、充满候选和无效数据清除；合计10项测试通过，尚未上板验收门限。

## 电流档位掉电保存

`settings.c/settings.h` 使用STM32G031C8最后两页（page30/31，各2KB），地址 `0x0800F000–0x0800FFFF`。
GCC链接脚本和Keil IROM均缩减为60KB（结束于0x0800EFFF），禁止程序占用配置区；后续CubeMX重新生成工程时必须保留此限制。
依据工程自带 `stm32g0xx_hal_flash.h` 的FLASH_PAGE_SIZE=0x800及DOUBLEWORD编程类型，HAL Flash/FlashEx完成写入。

- 菜单确认单路电流：三路档位打包保存，校验通过后应用GPIO；取消编辑不写入。
- 菜单“三路恢复100mA”：同样保存，复位后保持100mA。
- 档位未变化且已有相同记录：不重复写入。每次有效变化只追加16字节，单页128条；满页后擦除另一页并轮换。
- 记录包含格式版本、递增序号、三路档位、CRC32和最后写入的提交标记。写入失败不切换到新电流，菜单保留编辑页并显示SAVE FAILED SEE UART。
- 启动扫描两页选择最新有效记录；空白、版本不兼容、CRC损坏或档位非法记录跳过，完全无有效记录默认100mA。
- 换页先保留旧页，再擦另一页、写入和校验新记录；在正常Flash读回条件下，未提交记录不会替代旧记录。真正掉电中断编程可能涉及ECC/电压问题，仍须实板掉电测试，不宣称仿真覆盖物理故障。
- 串口输出FLASH LOAD/FLASH SAVE以及HAL错误码，保存失败不会被静默报告为成功。

普通断电重启保留设置，但整片擦除/全片下载会清掉配置；调试下载应选择仅擦应用使用的页，并确认工具不擦page30/31。
Flash保存会短暂阻塞主循环，LED/动画可能暂停数十毫秒；不在中断中写Flash，不修改选项字节。
恢复1000mA表示恢复上次选择的名义电流档位，复位初期仍为悬空100mA，且BQ24040自身限流/热调节仍有效。

新增真实Thumb仿真覆盖：三路独立恢复、相同值无重复写、提交中断回退、跨页换页保留旧记录、CRC损坏回退及全部100mA保存。
上板需要逐路设为不同档位后断电、重启验证串口/GPIO/OLED一致，并测试保存时断电及Flash写保护失败提示。
